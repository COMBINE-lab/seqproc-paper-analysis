# Aligned 32-thread validity campaign (2026-08-11)

This directory contains the machine-readable results used for the revised
manuscript validity table. Each tool was run once at 32 threads with the same
executable and qualitatively aligned configuration used by the performance
campaign.

The exact commands, inputs, checksums, output contracts, and tool provenance
are recorded in `frozen_manifest.yaml`. The LR-SPLiT-seq primary splitcode set
is the deduplicated analytical union of its forward and reverse-complement
passes. No duplicate-reconciliation time is included in the performance
campaign.

## Results

- `validity_metrics.{json,csv}`: emitted records and precision, recall, and F1
  against each protocol's conservative structural reference.
- `lr_forward_yield.csv`: materialized-output yield for the controlled
  forward-only LR-SPLiT-seq supplementary runs. Primary validity uses the
  capability-complete dual-orientation comparison.
- `pairwise_metrics.csv`: pairwise emitted-read set overlaps and Jaccard values.
- `venn_metrics.csv`: mutually exclusive three-tool overlap regions.
- `vtotal_provenance.json`: exact reference-building commands and checksums.
- `summarize_validity.py`: exact aggregation script used for these results.
- `execution-log.jsonl`: execution status for all 15 scheduled conditions.

The original frozen campaign completed all 15 tool conditions with exit code
zero. Two sci-RNA-seq3 conditions were nevertheless marked failed by incorrect
harness output contracts: matchbox validly emitted 29--30 nt projections while
the contract capped them at 28 nt, and splitcode intentionally suppressed the
raw pass-through output while writing the requested extracted output. The
already-produced FASTQs were audited directly; no tool was rerun. The corrected
contracts are in `contract_fixed_manifest.yaml`, generated by analysis-repository
commit `41c928a2501deaf6ee8ddff15c36e3e20e2de59b`.

`V_total` is a conservative, protocol-specific structural reference, not
experimental ground truth. In particular, its low coverage of LR-SPLiT-seq
input makes precision against it a conservative diagnostic rather than an
absolute false-positive rate.
